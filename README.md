# ระบบตรวจสอบใบลงเวลา (Check Salary)

เว็บแอพสำหรับให้พนักงานเข้ามาตรวจสอบใบลงเวลาของตัวเอง แล้วกด **ยืนยัน** หรือ **แจ้งแก้ไข**
ทำงานบน **Google Apps Script** และใช้ **Google Sheet** เป็นฐานข้อมูล ไฟล์ใบลงเวลาเก็บใน **Google Drive** ของผู้ดูแล

## ความสามารถ

### ผู้ดูแลระบบ (เจ้าของสคริปต์)
- **ภาพรวม** — เลือกเดือนแล้วดูว่าใครยังไม่ได้อัปโหลด ใครยังไม่เปิดดู ใครเปิดดูแล้ว ใครขอแก้ไข และใครยืนยันแล้ว พร้อมเวลาที่ยืนยัน
- **คำขอแก้ไขที่รอตอบ** — แสดงทุกเดือนที่พนักงานส่งข้อความมาแล้วยังไม่ได้ตอบ
- **อัปโหลดใบลงเวลา** — เลือกได้หลายไฟล์พร้อมกัน (PDF / JPG / PNG) ถ้าชื่อไฟล์มีรหัสพนักงาน เช่น `EMP001.pdf` ระบบจะจับคู่ให้อัตโนมัติ
- **ตอบกลับคำขอแก้ไข** และ **อัปโหลดฉบับแก้ไข** — ฉบับเดิมจะถูกเก็บเป็นประวัติ ส่วนฉบับใหม่พนักงานต้องยืนยันอีกครั้ง
- **จัดการพนักงาน** — เพิ่ม แก้ไขชื่อหรืออีเมล และลบได้ (ประวัติใบลงเวลาของคนที่ถูกลบยังเก็บไว้)
- **ประวัติกิจกรรม** ของแต่ละใบลงเวลา เช่น อัปโหลดเมื่อไร พนักงานเปิดดูกี่ครั้ง และยืนยันเมื่อไร

### พนักงาน
- ล็อกอินด้วย **อีเมลของตัวเอง** แล้วกรอก **รหัส OTP 6 หลัก** ที่ระบบส่งไปทางอีเมล
- ดูใบลงเวลาของตัวเองได้ทุกเดือน (เห็นเฉพาะของตัวเอง) และดาวน์โหลดได้
- กด **"ยืนยันว่าถูกต้อง"** ได้หลังเปิดดูไฟล์แล้ว เมื่อยืนยันแล้วจะล็อกทันทีและแก้ไขไม่ได้
- กด **"แจ้งแก้ไขเวลา"** เพื่อพิมพ์รายละเอียดที่ไม่ตรง แล้วคุยต่อกับผู้ดูแลได้

### หลักฐานการยืนยัน
เมื่อพนักงานกดยืนยัน ระบบจะบันทึกข้อมูลต่อไปนี้ลงชีต `ใบลงเวลา`
- **เวลาที่ยืนยัน** ซึ่งเป็นเวลาของเซิร์ฟเวอร์ Google ไม่ใช่เวลาบนเครื่องของพนักงาน
- **รายละเอียดการยืนยัน** ได้แก่ อีเมล วันเวลา ฉบับที่ อุปกรณ์ที่ใช้ และ **SHA-256 ของไฟล์** ซึ่งใช้พิสูจน์ได้ว่าพนักงานยืนยันไฟล์ฉบับไหน
- **เวลาที่เปิดดูครั้งแรกและครั้งล่าสุด** รวมถึงจำนวนครั้งที่เปิดดู

ทุกการกระทำจะถูกบันทึกเพิ่มในชีต `บันทึกกิจกรรม` ด้วย

## วิธีติดตั้ง (ประมาณ 10 นาที)

### 1) สร้างโปรเจกต์ Apps Script
1. ไปที่ <https://script.google.com> แล้วกด **โปรเจกต์ใหม่ (New project)** จากนั้นตั้งชื่อ เช่น `ระบบตรวจสอบใบลงเวลา`
2. กดไอคอนเฟือง **การตั้งค่าโปรเจกต์ (Project Settings)** แล้วติ๊ก **"แสดงไฟล์ Manifest appsscript.json ในเครื่องมือแก้ไข"**
3. กลับไปที่หน้า **เครื่องมือแก้ไข (Editor)** แล้วสร้างไฟล์ให้ครบตามตารางด้านล่าง โดยคัดลอกเนื้อหาจากโฟลเดอร์ [`src/`](src/) ไปวาง

   | ประเภท (กด + ข้าง "ไฟล์") | ชื่อไฟล์ที่ต้องตั้ง (ไม่ต้องพิมพ์นามสกุล) | คัดลอกจาก |
   |---|---|---|
   | สคริปต์ | `Config` | `src/Config.gs` |
   | สคริปต์ | `Db` | `src/Db.gs` |
   | สคริปต์ | `Auth` | `src/Auth.gs` |
   | สคริปต์ | `Employee` | `src/Employee.gs` |
   | สคริปต์ | `Admin` | `src/Admin.gs` |
   | สคริปต์ | `Code` (มีอยู่แล้ว วางทับได้เลย) | `src/Code.gs` |
   | HTML | `Index` | `src/Index.html` |
   | HTML | `Styles` | `src/Styles.html` |
   | HTML | `ClientCore` | `src/ClientCore.html` |
   | HTML | `ClientEmployee` | `src/ClientEmployee.html` |
   | HTML | `ClientAdmin` | `src/ClientAdmin.html` |
   | (มีอยู่แล้ว) | `appsscript.json` | `src/appsscript.json` |

4. กด **บันทึก** (Ctrl+S)

> ถ้าใช้ [clasp](https://github.com/google/clasp) เป็น ทำแบบนี้แทนได้ทั้งหมด
> `clasp login` → `clasp create --type standalone --title "ระบบตรวจสอบใบลงเวลา" --rootDir src` → `clasp push`

### 2) ตั้งค่าครั้งแรก
1. ที่แถบด้านบนของเครื่องมือแก้ไข เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้ (Run)**
2. Google จะขอสิทธิ์ ให้กด **ตรวจสอบสิทธิ์** แล้วเลือกบัญชีของคุณ
   ถ้ามีหน้าเตือน "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง (Advanced)** แล้วกด **ไปที่ ... (ไม่ปลอดภัย)** ซึ่งเป็นเรื่องปกติของสคริปต์ที่เขียนเอง
3. ดู **บันทึกการดำเนินการ (Execution log)** ระบบจะแสดงลิงก์ของ
   - Google Sheet ที่ใช้เป็นฐานข้อมูล ซึ่งระบบสร้างให้อัตโนมัติ
   - โฟลเดอร์ Google Drive ที่ใช้เก็บไฟล์ใบลงเวลา

### 3) เผยแพร่เป็นเว็บแอพ
1. กด **การทำให้ใช้งานได้ (Deploy)** แล้วเลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดเฟืองข้าง "เลือกประเภท" แล้วเลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้
   - **เรียกใช้ในฐานะ (Execute as): ฉัน (Me)** ← สำคัญ
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)** ← สำคัญ เพราะพนักงานยืนยันตัวตนด้วย OTP อยู่แล้ว
4. กด **ทำให้ใช้งานได้ (Deploy)** แล้ว **คัดลอก URL ของเว็บแอพ** ซึ่งลงท้ายด้วย `/exec`

### 4) เริ่มใช้งาน
1. เปิด URL แล้วกรอก **อีเมล Gmail ของคุณเอง** (บัญชีที่สร้างสคริปต์) เพื่อรับรหัส OTP ระบบจะเข้าหน้าผู้ดูแลให้อัตโนมัติ
2. ไปที่แท็บ **จัดการพนักงาน** แล้วเพิ่มรหัส ชื่อ และอีเมลของพนักงานแต่ละคน
3. ไปที่แท็บ **อัปโหลดใบลงเวลา** แล้วเลือกเดือนและแนบไฟล์
4. ส่ง URL เดียวกันให้พนักงาน พนักงานจะเข้าหน้าของตัวเองเมื่อล็อกอินด้วยอีเมลที่คุณเพิ่มไว้

### การอัปเดตโค้ดในภายหลัง
แก้ไขโค้ดแล้วไปที่ **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments)** กดดินสอแก้ไข เลือก **เวอร์ชัน: เวอร์ชันใหม่** แล้วกด Deploy วิธีนี้ทำให้ **URL เดิมยังใช้ได้**

## โครงสร้างข้อมูลใน Google Sheet

| ชีต | เก็บอะไร |
|---|---|
| `พนักงาน` | รหัสพนักงาน ชื่อ-นามสกุล อีเมล และวันที่เพิ่ม |
| `ใบลงเวลา` | 1 แถวต่อ 1 ไฟล์ (1 ฉบับ) ได้แก่ รอบเดือน ฉบับที่ สถานะ ไฟล์ SHA-256 เวลาเปิดดู **เวลาที่ยืนยัน** และรายละเอียดการยืนยัน |
| `ข้อความแก้ไข` | ข้อความระหว่างพนักงานกับผู้ดูแล |
| `บันทึกกิจกรรม` | บันทึกทุกการกระทำ เช่น ล็อกอิน เปิดดู ยืนยัน อัปโหลด เพิ่มหรือลบพนักงาน |

สถานะใบลงเวลามีดังนี้ `รอตรวจสอบ` → `ขอแก้ไข` → `ยืนยันแล้ว` ส่วนฉบับเก่าที่มีฉบับใหม่มาแทนจะมีสถานะ `ถูกแทนที่`

> ⚠️ **อย่าเปลี่ยนชื่อชีต และอย่าสลับลำดับคอลัมน์** เพราะระบบอ่านข้อมูลตามตำแหน่งคอลัมน์
> ถ้าต้องการใช้หลักฐานให้น่าเชื่อถือยิ่งขึ้น แนะนำให้ตั้ง **ป้องกันชีต (Protect sheet)** ไว้ เพื่อกันการแก้ไขโดยไม่ตั้งใจ

## ข้อควรรู้
- **โควตาอีเมล:** บัญชี Gmail ส่งอีเมลจากสคริปต์ได้ประมาณ **100 ฉบับต่อวัน** และการล็อกอิน 1 ครั้งใช้ 1 ฉบับ เมื่อล็อกอินแล้วจะอยู่ในระบบได้ 6 ชั่วโมง (Google Workspace ได้ 1,500 ฉบับต่อวัน)
- **ความปลอดภัย:** รหัส OTP ใช้ได้ 10 นาที กรอกผิดได้ไม่เกิน 5 ครั้ง และขอรหัสใหม่ได้ทุก 1 นาที พนักงานไม่มีสิทธิ์เข้า Google Sheet หรือ Drive โดยตรง ทุกอย่างผ่านสคริปต์ที่รันด้วยสิทธิ์ของคุณ เมื่อลบพนักงานแล้วพนักงานคนนั้นจะถูกตัดสิทธิ์ทันที
- ด้านบนของหน้าเว็บจะมีแถบ *"แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script"* ซึ่งเป็นข้อกำหนดของ Google สำหรับบัญชี Gmail ทั่วไป
- ขนาดไฟล์สูงสุด 10 MB ต่อไฟล์ ปรับได้ที่ `MAX_FILE_MB` ใน `Config.gs` และ `MAX_MB` ใน `ClientAdmin.html`
